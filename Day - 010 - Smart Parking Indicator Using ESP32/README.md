# Day 10 - Smart Parking Indicator Using ESP32

## 📅 Date

17 July 2026

## 📌 Project Overview

This project implements a Smart Parking Indicator using an ESP32, an HC-SR04 Ultrasonic Sensor, three LEDs, and a buzzer. The ultrasonic sensor continuously measures the distance between the vehicle and the parking wall. Based on the measured distance, LEDs and a buzzer provide visual and audio feedback to assist in safe parking.

## 🎯 Objective

* Measure distance using an ultrasonic sensor
* Process sensor data in real time
* Control multiple LEDs based on distance thresholds
* Activate a buzzer when the object is too close
* Simulate a real-world parking assistance system
