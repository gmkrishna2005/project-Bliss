# Day 11 - Servo Motor Control Using ESP32

## 📌 Project Overview

This project demonstrates how to control the angular position of an SG90 servo motor using an ESP32. The servo is rotated between different angles by generating PWM signals, introducing the fundamentals of position control used in robotics and automation.

## 🎯 Objective

* Learn how servo motors work
* Generate PWM signals using the ESP32
* Control the servo position accurately
* Understand angle-to-PWM mapping

## 🛠️ Hardware

* ESP32 Development Board
* SG90 Servo Motor
* Breadboard (optional)
* Jumper Wires
* USB Cable
* External 5V Power Supply *(recommended)*

## 💻 Software

* Arduino IDE
* Arduino Core for ESP32
* ESP32Servo Library

## 🛠️ Technologies Used

* ESP32 Development Board
* SG90 Servo Motor
* C++
* Arduino Framework
* PWM
* ESP32Servo Library
* Embedded Systems
* Git
* GitHub

## 📖 What I Learned

* Working principle of servo motors
* Generating PWM signals for position control
* Rotating the servo to specific angles
* Using the ESP32Servo library
